# Aces Pup - Dog vs Cat Air Combat

A fun and comical rail shooter game where dogs pilot planes to fight cats in the sky!

## Game Concept

- **Genre**: Rail Shooter (Space Harrier style)
- **Theme**: Dogs vs Cats in aerial combat
- **Perspective**: Behind the dog pilot (3rd person)
- **Art Style**: Minimal art requirements using colored rectangles and shapes

## Features

### Character Selection
Choose from 3 unique dog aces:
- **Rex** - Beagle Male (Adult) - Balanced speed and fire rate
- **Luna** - Dachshund Female (Adult) - Fast movement, good fire rate  
- **Paco** - Chihuahua Male (Teen) - Very fast, rapid fire

### Gameplay
- **Movement**: Arrow keys to move around the screen
- **Shooting**: Spacebar to fire
- **Enemies**: Cats in planes flying at you
- **Boss Battles**: Special cat pilots with unique patterns and multiple health
- **Scoring**: Points for each cat destroyed, bonus for bosses

### Game Mechanics
- **One Shot Kill**: Both player and regular enemies die in one hit
- **Boss Health**: Boss cats take multiple shots to destroy
- **Wave System**: Progress through waves with increasing difficulty
- **Boss Spawn**: Boss appears after reaching certain score thresholds

## Controls

### Character Select
- **LEFT/RIGHT**: Select character
- **ENTER**: Choose character and start game

### In-Game
- **Arrow Keys**: Move dog plane
- **SPACEBAR**: Fire weapon

### Game Over
- **R**: Restart game
- **Q**: Quit game

## Technical Details

- **Engine**: Pygame
- **Resolution**: 1200x800
- **FPS**: 60
- **Language**: Python 3

## Installation

1. Ensure Python 3 is installed
2. Install Pygame: `pip install pygame`
3. Run the game: `python main.py`
