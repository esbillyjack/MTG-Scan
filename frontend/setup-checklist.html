🚀 MOX/Mtgscanner Setup Checklist

Complete setup guide for collaborative development

0% Complete

🎯 Prerequisites

  • Install Python 3.12+ from python.org
  • Install Git from git-scm.com
  • Install Cursor AI from cursor.sh
  • Create GitHub account at github.com
  • Get access to repository (dad will add you as collaborator)

🎯 Repository Setup

  • Clone the repository:
    git clone https://github.com/esbillyjack/MTG-Scan.git cd MTG-Scan
  • Verify you're on develop branch:
    git branch # Should show: * develop
  • Check repository access (ask dad if you can't clone)

🎯 Python Environment

  • Create virtual environment:
    python3 -m venv venv
  • Activate virtual environment:
    # On Mac/Linux: source venv/bin/activate # On Windows: venv\Scripts\activate
  • Install dependencies:
    pip install -r requirements.txt pip install fastapi uvicorn sqlalchemy psycopg2-binary python-dotenv

🎯 Configuration

  • Copy environment template:
    cp railway-env-template.txt .env
  • Edit .env file with your API keys (ask dad for these)
  • Verify environment variables are loaded:
    echo $ENV_MODE echo $OPENAI_API_KEY

🎯 Start Development Server

  • Activate environment and start server:
    source venv/bin/activate source .env python backend/app.py
  • Open browser to http://localhost:8001
  • Verify Magic Card Scanner interface loads
  • Test upload functionality with a Magic card image

🎯 Development Workflow

  • Create feature branch:
    git checkout -b feature/your-feature-name
  • Make your changes and test locally
  • Commit your changes:
    git add . git commit -m "Add your feature description" git push origin feature/your-feature-name
  • Create pull request on GitHub for dad to review

🎯 Using Cursor AI

  • Open project in Cursor:
    cursor MTG-Scan
  • Ask Cursor AI for help with:
    • "How do I add a new feature to scan Magic cards?"
    • "Review this code for bugs"
    • "Explain how the card scanning works"
    • "Help me debug this issue"
⚠️ Safety Reminders:
  • Always work locally first (http://localhost:8001)
  • Never edit production directly
  • Create pull requests for all changes
  • Ask dad for API keys and database access
🎉 You're Ready!

Once you complete this checklist, you can:

  • Run the application locally
  • Upload and scan Magic cards
  • View the collection database
  • Make code changes safely
  • Use Cursor AI for help
  • Collaborate with dad
